# AID 30+ 집중캠프 랜딩 리뉴얼

> 신청 전환·검색 노출·접근성·성능·UI 인터랙션·이미지 최적화 전반을 정비한 모집 페이지 품질 강화

## 🚀 신청·전환

- **신청 폼 골격 구축** — 깨진 신청 경로(빈 mailto·비활성 8개) 정상화, 구글폼 버튼 구조로 전환
- **흐름 단순화** — 헤더/APPLY "신청하기" → 일정 섹션으로 부드러운 내부 스크롤 → 회차별 "접수하기"가 구글폼 새 탭으로 열림
- **단일 지점 제어** — `SCHEDULE_FORM_URL` 한 곳만 채우면 라이브
- **준비중 뱃지** — 회차별 "접수하기" 8개에 시각적 비활성 상태 명확화
- **FAQ 섹션 신설** — 신청 전 반론(비용·자격·시간·혜택 등) 처리 6문항, 네이티브 아코디언

## 🔍 검색·공유

- **메타·OG·트위터카드** 신설 — 카톡·SNS 공유 시 미리보기 정상 출력
- **구조화 데이터** — `Course` + `FAQPage` JSON-LD 추가 (검색 리치 결과 노출 기회)
- **공식 도메인 `aid.weniv.co.kr`** 반영 (canonical / og:url / JSON-LD)
- **OG 대표 이미지** 추가 후 경량화 (1.7MB PNG → 239KB JPG)

## ♿️ 접근성·성능

- **WCAG AA 색 대비** 통과 — 보조 텍스트·primary 색 미세 보정
- **키보드 접근성** — `:focus-visible` 아웃라인, 본문 바로가기(skip-link)
- **히어로 3D 안정성** — `prefers-reduced-motion` 시 정적 프레임, WebGL 실패 시 그라디언트 폴백
- **폰트 2MB 단일 → dynamic-subset 자체 호스팅** — 브라우저가 실제 사용 범위만 다운로드
- **Three.js CDN preconnect**, **이미지 CLS 치수** 안정화
- **prettier 포맷팅** 일관화

## 🖼 이미지 경량화

- **강사 사진** 3334px PNG → 800px + WebP 폴백 *(약 93%↓)*
- **OG 이미지** 1.7MB PNG → 239KB JPG *(약 86%↓)*

## ✨ UI/UX 인터랙션

- **히어로 풀 뷰포트** (`100dvh`) + 하단 스크롤 버튼 **클릭 가능** → 부드러운 앵커 스크롤
- **카드 스크롤 등장 애니메이션** — About / Tracks / Structure 선별 적용, Structure는 1→2→3→4 순차 stagger
- **헤더 nav 스크롤스파이** — 현재 보고 있는 섹션 자동 강조
- **브랜드 로고 SVG화** + 파비콘 연결 (벡터로 모든 해상도 선명)
- **버튼 hover 보강** — 히어로 outline 버튼 브랜드 톤 강조
