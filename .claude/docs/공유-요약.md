# AID 30+ 집중캠프 랜딩 개선

> 신청 흐름·검색 노출·접근성·성능·UI를 정비한 모집 페이지 품질 강화 라운드

## 🚀 신청·전환

- 깨진 신청 경로 정상화, 구글폼 버튼 구조로 골격화 (URL만 받으면 라이브)
- 신청·접수 버튼 **독립 제어** — 회차 일정 확정 시 별도 활성화
- **FAQ 섹션 신설** (6문항·네이티브 아코디언)

## 🔍 검색·공유

- OG / 트위터카드 / `Course`·`FAQPage` 구조화 데이터 신설
- 공식 도메인 `aid.weniv.co.kr` 반영, OG 대표 이미지 추가

## ♿️ 접근성·성능

- WCAG AA 색 대비, 키보드 포커스, 본문 바로가기
- 히어로 3D `prefers-reduced-motion`·WebGL fallback
- 폰트 2MB → 공식 dynamic-subset 자체 호스팅

## 🖼 이미지 경량화

- 강사 사진: 3334px PNG → 800px + WebP 폴백 (**−93%**)
- OG 이미지: 1.7MB → 239KB (**−86%**)

## ✨ UI/UX

- 카드 스크롤 등장 애니메이션 (선별 적용)
- 헤더 nav **스크롤스파이** — 현재 섹션 자동 강조
