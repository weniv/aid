# 요구사항-07 · FAQ 섹션 신설 (CRO + SEO)

> 담당 관점: cro-optimizer(반론 처리) + seo-specialist(FAQPage)
> 상태: **완료**
> 작성일: 2026-05-29

---

## 1. 목적

- **CRO**: 신청 전 마지막 반론(비용·자격·시간·혜택·선발)을 해소해 전환 이탈 감소.
- **SEO**: `FAQPage` 구조화 데이터로 검색 리치 결과 노출 기회 확보.

## 2. 적용 내용

### 마크업 (`index.html`)
- SCHEDULE → **FAQ** → APPLY 순서로 신설(`id="faq"`, `section--faq`, 배경 흰색으로 리듬 유지).
- **네이티브 `<details>/<summary>`** 사용 → JS 불필요, 키보드/스크린리더 기본 지원(접근성).
- 헤더 nav 에 `FAQ` 링크 추가.
- Q&A 6개(사실 기반):
  1. 수강료 — 100% 정부 지원(무료)
  2. 지원 자격 — 제주 30+ 재직자(또는 최근 3년 직무경험)
  3. 비전공자 가능 — G트랙 등 입문 과정
  4. 재직 병행 시간 — 평일 저녁/주말반, 총 12h(온5+오7)·4주
  5. 수료 혜택 — 디지털 배지
  6. 신청·선발 — 선착순 접수 후 자격 확인·선발, 일정 추후 공지

### 스타일 (`assets/landing.css`)
- `.faq-list`/`.faq-item`/`summary` — 토큰 기반, 절제된 아코디언. `+` → `×`(45° 회전) 토글 표시.

### 구조화 데이터 (`index.html` head)
- `FAQPage` JSON-LD 추가(6개 Question/Answer) — **화면 노출 텍스트와 100% 일치**(Google 가이드라인 준수). Course JSON-LD와 함께 총 2블록, 모두 유효 파싱 확인.

## 3. 톤 원칙

- 사용자 선호(절제) 준수: 마케팅성 과장 없이 **사실·간결**. 6개로 제한, 빽빽하지 않게.

## 4. 검증

- faq-item 6 · id/nav 링크 반영 · JSON-LD 2블록(Course+FAQPage) 유효 · dev 서버 200.

## 5. 후속(선택)

- 운영 확정 시 FAQ 보강(환불 규정·교재·온라인 플랫폼 등).
- 선발 소요일([추후적용-항목 #4]) 확정 시 6번 답변 구체화.
