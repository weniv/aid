# 요구사항-02 · SEO / OG / 구조화 데이터 (P1)

> 담당 관점: seo-specialist (검색 최적화)
> 상태: **구현 완료 / OG 대표 이미지 에셋만 대기**
> 작성일: 2026-05-28

---

## 1. 배경 · 문제

- 공유·검색 메타가 사실상 전무했음 → 카카오톡·SNS 공유 시 **썸네일·제목 없는 맨 링크**로 노출 (모집은 공유로 퍼지는데 클릭률 손실).
- 착수 전 상태(실측): **OG 0 · 트위터카드 0 · JSON-LD 0**. `<title>`·`description`·`lang=ko`만 존재.
- 공식 도메인 확정(`https://aid.weniv.co.kr/`)으로 canonical/OG `url` 입력값 확보 → 구글폼 URL과 무관하게 단독 완료 가능해 P1으로 선행.

## 2. 적용 내용 (`index.html` `<head>`)

| 항목 | 내용 |
|---|---|
| Canonical | `https://aid.weniv.co.kr/` |
| robots | `index, follow` |
| theme-color | `#2e6ff2` (브랜드 primary) |
| Open Graph | type/site_name/title/description/url/image/image:width(1200)/height(630)/locale(ko_KR) — 총 9개 |
| Twitter | `summary_large_image` + title/description/image — 총 4개 |
| 구조화 데이터 | `Course` JSON-LD (provider 제주대, 무료(price 0), courseMode blended, courseWorkload PT12H, 위치 제주대) |

- **검증**: OG 9 · 트위터 4 · JSON-LD 1(파싱 OK) · canonical 1 · h1 단일 · dev 서버 HTTP 200.
- **사실 기반 원칙 준수**: 가짜 평점·리뷰 마크업 없음. 무료(정부지원)·12시간·블렌디드·4트랙 등 확정 사실만 사용.

## 3. 카피(메타) 톤

- 페이지 본문이 아닌 **메타데이터**이므로 베네핏 중심 사실 표기 사용: "4주 AI·디지털 집중과정 · 교육비 100% 정부 지원".
- 과장·허위 없음. (본문 카피의 "절제" 원칙과 별개 영역)

## 4. 남은 일 / 후속

- **OG 대표 이미지(1200×630) 제작 필요** → `assets/og-image.png` 저장하면 태그는 이미 연결됨. ([추후적용-항목 #7](추후적용-항목.md))
- 푸터에 도메인/공식 링크 노출은 푸터 작업 시 ([추후적용-항목 #6](추후적용-항목.md)).
- (선택) FAQ 섹션 신설 시 `FAQPage` JSON-LD 추가 — CRO의 반론처리 FAQ와 연동.
- 배포 후 점검: 카카오 디버거 / 페이스북 공유 디버거 / Google Rich Results Test 로 미리보기·리치결과 확인.
