# 요구사항-06 · 이미지 최적화 (P3)

> 담당 관점: image-optimizer
> 상태: **강사 이미지 완료 / OG·WebP는 선택 후속**
> 작성일: 2026-05-29

---

## 1. 배경

강사 이미지가 표시 크기(약 420px) 대비 **3334px**로 과대(각 350KB/234KB). 하단·`loading="lazy"`라 LCP 비영향이나 불필요한 용량.

## 2. 적용 완료 (도구: macOS `sips`, 설치 불필요)

- `assets/images/instructors/lhj.png` 3334px **350KB → 800px 163KB**
- `assets/images/instructors/kms.png` 3334px **234KB → 800px 108KB**
- 합계 **585KB → 271KB (~54%↓)**, **PNG/알파 유지**(투명 채널 보존), 원본은 git 이력에 보존.
- `index.html` 강사 `<img>` 치수 `3334` → `800` 보정 (CLS 정확도).
- 검증: 800px 2곳 반영 · 3334 잔존 0 · dev 서버 200.

### 해상도 근거
- 카드 미디어 표시 ~420px → 레티나 2x ~840px. 800px는 사실상 2x 수준(사진이라 미세 차이 비가시).

## 3. 미적용 / 선택 후속

| 항목 | 상태 | 비고 |
|---|---|---|
| WebP 변환 | ✅ **완료** | `brew install webp`(cwebp 1.6.0) 설치 후 변환: lhj **163KB→27KB**, kms **108KB→12KB**(알파 유지). `<picture>` 로 WebP source + PNG 폴백. CSS `.faculty-card__media picture{display:block}` 보강 |
| OG 이미지 1.7MB | ✅ **완료** | 알파 없음 확인 → JPG q90 변환: **1.7MB PNG → 239KB JPG(86%↓, 1200×658)**. `assets/og-image.jpg` 신규, 기존 png 제거, head 의 og/twitter image·치수(1200×658) 갱신 |

## 4. 우선순위 맥락

P0 신청([01]) → P1 SEO([02]) → P2 히어로 a11y([03]) → P2 폰트/LCP([04]) → P2 WCAG([05]) → **P3 이미지(본 문서)**.
P1·P2 핵심 + P3 강사 이미지까지 완료. 남은 건 선택적 후속(WebP·OG 경량화)과 대기 항목(구글폼 URL·회차 일정).
