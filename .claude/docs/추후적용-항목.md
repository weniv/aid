## 1. 신청 데이터 수신처 — ⏳ 방식 확정, URL만 대기

- **확정 방식**: **구글폼** / 버튼 누르면 **새 탭으로 이동**(임베드 아님).
- **대기 중**: 구글폼 **URL** (예: `https://forms.gle/xxxx`)
- **플로우 단순화(2026-06-01)**: 헤더 "신청하기"·APPLY "신청하기" → `#schedule` 내부 스크롤 → SCHEDULE 회차별 "접수하기"에서 구글폼 오픈.
- **단일 지점 제어**: `assets/apply-link.js` 의 `SCHEDULE_FORM_URL` **한 곳만** 채우면 SCHEDULE 8개 버튼이 새 탭 구글폼으로 활성화. 미입력 시 자동으로 `aria-disabled` + **"준비중" 뱃지** 유지.
- **URL 수령 시 할 일**: `SCHEDULE_FORM_URL` 에 URL 입력 → 끝. (그 외 수정 불필요)
- **메모**: 구글폼은 동의서를 폼 내부에서 수집(항목 3 참조). 데이터가 구글(해외) 저장 — 동의서 고지문에 위탁/국외이전 안내 권장.

## 2. 개인정보 보유기간 — ✅ 확정: 5년

- **반영 완료(2026-05-28)**: APPLY 섹션 `.apply-consent` 문구에 "5년간 보관 후 파기" 반영.
- **추가 반영 위치(구글폼 작성 시)**: 구글폼 내 개인정보 수집·이용 동의서 고지문에 동일 적용.

## 3. 개인정보 처리방침 — ✅ 확정 (방식 변경)

- **확정 방식**: 별도 처리방침 페이지/URL을 두지 않고, **신청서(구글폼)에서 개별로 개인정보 수집·이용 동의서를 수령**.
- **반영 완료(2026-05-28)**: 랜딩 APPLY에는 "신청서 작성 시 동의를 받는다"는 안내만 노출(`.apply-consent`). 처리방침 링크는 두지 않음.
- **구글폼 작성 시 할 일**: 폼 첫 섹션에 수집 항목·이용 목적·보유기간(5년)·동의 체크(필수)를 포함한 **동의서 문항**을 넣을 것. (해외 저장 위탁/국외이전 고지 포함 권장)

## 4. 선발 안내 소요일

- **현재 상태**: **선발 절차 자체는 사업계획서에 확정**되어 있으나, "신청 후 며칠 내 안내"의 정확한 영업일 값은 미정.
- **사업계획서 기준 선발 절차(참고)**:
  - 신청기간: **캠프 개시 4주 전 ~ 2주 전(2주간)**, 선착순 330명(정원 300 + 예비 30)
  - 1차 서류심사: 기본요건(① 만 30세↑ ② 재직 또는 최근 3년 직무경험 ③ 제주 거주·근무) → 110%(330명) 면접대상 공지, 미충족자 즉시 탈락 통보(이의제기 3일)
  - 2차 면접: **캠프 개시 1주일 전**, 개인면접 15분 또는 영상면접
  - 최종 합격: 면접점수순 300명(회당 30명×10회), **이메일+문자 통보**, 예비자(31~50위) 대기
- **확정 시 받을 것**: 폼에 표기할 "신청 후 OO일 내 안내" 문구의 정확한 값
- **확정 시 적용 위치**: 신청 폼 하단 안내문(요구사항-01 §7 `.apply-form__note`), FAQ.
- **메모**: 위 절차상 "선착순 접수 후 서류+면접"이므로, 폼은 **1차 접수**일 뿐 즉시 확정이 아님. 안내 문구를 "접수 → 선발(서류·면접) → 합격 통보" 흐름에 맞춰 작성할 것.

## 5. 모집 시기 / 회차 일정

- **현재 상태**: **7월 시작(잠정)**, 세부 모집 시기·회차별 접수/교육 일정 미정.
- **사업계획서 예시 일정(참고 — 확정 아님)**:
  - 1회차: 접수 2026.7.1~7.30 / 교육 2026.8.2~9.14

- **확정 시 받을 것**: 회차별 접수기간·온라인/오프라인 교육기간
- **확정 시 적용 위치**:
  - `index.html` SCHEDULE 테이블의 "미정" 8칸,
  - `assets/apply-link.js` 의 `SCHEDULE_FORM_URL` 입력 → **SCHEDULE 접수 버튼 8개 활성화** (방안 B: 일정 확정 전까지는 비활성 유지),

- **메모**: 방안 B 적용으로 SCHEDULE 접수 버튼은 APPLY 버튼과 독립. 일정이 "미정"인 동안 접수 버튼은 "준비중"으로 두고, 회차 확정 시 함께 켠다. 일정 확정 전까지는 SCHEDULE를 "7월 오픈 예정 + 알림 신청" 형태로 바꾸는 것도 권장(전환 이탈 방지).
