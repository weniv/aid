# 요구사항-04 · 폰트 / LCP (P2)

> 담당 관점: perf-a11y-auditor (성능)
> 상태: **완료** (preconnect/CLS + 폰트 dynamic-subset 자체 호스팅 적용)
> 작성일: 2026-05-28 (폰트 결정 반영: 2026-05-28)

---

## 1. 배경 · 현황

- LCP 후보는 **히어로 h1 텍스트**(히어로엔 이미지 LCP 요소 없음, 배경은 canvas/그라디언트).
- 폰트 `style/fonts/pretendard.woff2` = **2MB** 가변폰트(weight 45~920, 전체 한글). `font-display:swap` + `Pretendard Fallback`(Arial 메트릭 오버라이드) 적용돼 있어 **텍스트는 폴백으로 즉시 표시 → LCP는 이미 양호**, 폰트 로드 후 스왑.
- 강사 이미지 `lhj.png`/`kms.png` = **3334×3334**(표시 크기 대비 과대, 각 350KB/234KB). 단 하단·`loading="lazy"`라 LCP 비영향.
- OG 이미지(1.7MB)는 페이지에서 로드되지 않음(메타 전용) → 페이지 LCP 무관.

## 2. 적용 완료 (도구 불필요·안전)

| 항목 | 내용 |
|---|---|
| preconnect | `unpkg.com`, `ga.jspm.io` 조기 연결 → Three.js(히어로 3D) 로드 단축 |
| 이미지 CLS | 강사 `<img>` 에 `width/height(3334)` + `decoding="async"` 추가 (레이아웃 점프 방지) |

- 검증: preconnect 2 · img dims 2 · dev 서버 HTTP 200.

## 3. ⚠️ 폰트 본체(2MB) — 의사결정 필요

2MB가 가장 무거운 자산. **2MB를 그대로 preload 하는 것은 안티패턴**(대역폭 경합)이라 적용하지 않음. swap+폴백이 LCP는 이미 가려줌. 진짜 해결은 **용량 축소**이며 세 가지 선택지:

| 옵션 | 방법 | 장점 | 단점 |
|---|---|---|---|
| **A. 로컬 서브셋** | `fonttools(pyftsubset)` 설치 후 한글 상용(KS X 1001 2350자)+Latin+기호로 서브셋, 가변축 유지 → ~300~500KB | 자체 호스팅 유지, 대폭 경량 | **fonttools 설치 필요**(현재 미설치), 상용 외 글자 누락 위험(향후 콘텐츠 편집 시) |
| **B. Pretendard 공식 dynamic-subset** | unicode-range로 쪼갠 공식 서브셋 셋 사용(자체 호스팅 or CDN) | 필요한 글자 범위만 on-demand 로드, **글자 누락 없음** | 파일 多(자체 호스팅 시) 또는 CDN 외부 의존 추가 |
| **C. 현행 유지** | 그대로 둠 | 작업 0, 이미 swap+폴백으로 LCP 양호 | 폰트 스왑까지 2MB 다운로드(특히 모바일/저속) |

- **권장**: 콘텐츠가 계속 바뀌는 모집 페이지라 글자 누락이 치명적 → **B(공식 dynamic-subset)** 가 가장 안전. 자체 호스팅을 고수하면 B를 로컬에 받아 두고, 외부 의존을 허용하면 CDN.
- A는 "현재 페이지 글자만" 서브셋하면 가장 작지만 **일정·이름 등 추가 시 깨질 수 있어 비권장**. 상용 2350자 서브셋이면 대부분 커버되나 100% 보장은 아님.

### ✅ 결정·적용 결과 (2026-05-28): B + 자체 호스팅

- Pretendard **v1.3.9** 공식 variable dynamic-subset 채택, **자체 호스팅**(외부 CDN 의존 없음 — 공공/교육망 차단·장애에도 안전).
- 다운로드/배치:
  - `style/fonts/pretendard-dynamic-subset.css` (92개 `@font-face`, unicode-range별)
  - `style/fonts/woff2-dynamic-subset/PretendardVariable.subset.{0..91}.woff2` (92개, 총 ~3MB **디스크**)
- 패밀리명 `'Pretendard Variable'` → **`'Pretendard'`** 로 보정해 기존 `base.css` 참조(`font-family:"Pretendard"`) 그대로 호환. `font-weight: 45 920` 가변축 유지.
- `style/fonts.css`: 기존 단일 2MB `@font-face` → `@import url("./fonts/pretendard-dynamic-subset.css")` 로 교체, `Pretendard Fallback`(Arial 메트릭) 유지.
- **기존 `style/fonts/pretendard.woff2`(2MB) 삭제**(git rm).
- **효과**: 디스크 총량은 비슷하나 **브라우저는 페이지에 실제 쓰인 유니코드 범위의 서브셋만 다운로드** → 초기 폰트 전송량 대폭 감소(2MB 일괄 → 사용 범위만).
- 검증: woff2 92/92 유효(wOF2 매직바이트) · 패밀리 보정 확인 · 경로 정합 · dev 서버 HTTP 200.

- 배포 후 Lighthouse(LCP/CLS/INP) 실측.
