# 요구사항-05 · WCAG 접근성 (P2)

> 담당 관점: perf-a11y-auditor (웹접근성)
> 상태: **핵심 수정 완료 / primary 버튼 대비는 의사결정 대기**
> 작성일: 2026-05-29

---

## 1. 배경

정부·교육 사이트라 웹 접근성(KWCAG/WCAG AA) 중요. 실측 감사로 명확한 실패 항목 확인.

## 2. 감사 결과 (실측 대비비)

| 조합 | 대비 | 판정 |
|---|---|---|
| `grayLv3`(#8d9299) 텍스트 / 흰배경 | 3.13:1 | ❌ 일반텍스트 |
| `grayLv3` 텍스트 / 연회색섹션(grayLv1) | 2.87:1 | ❌ |
| `grayLv3-aA11y`(#6c7074) / 흰 | 4.99:1 | ✅ |
| `grayLv3-aA11y` / 연회색 | 4.58:1 | ✅ |
| `grayLv4`(본문) / 흰·회색 | 9.0 / 8.3 | ✅ |
| 흰 글씨 / `primary`(#2e6ff2) 버튼 | 4.49:1 | 🔸 0.01 미달 |
| focus 스타일 · skip 링크 | 없음 | ❌ |

- rem 기준 10px → 13px 보조텍스트는 "일반텍스트"(4.5 필요).
- `grayLv3`는 landing/components에서 **전부 텍스트 색**으로만 사용(보더·점은 `grayLv3-rgb` 별도) → 텍스트만 교체 가능.

## 3. 적용 완료

| 항목 | 처리 |
|---|---|
| 텍스트 대비 | `color: var(--grayLv3)` → `var(--grayLv3-aA11y)` (landing 16곳 + components 3곳). 디자인 토큰 정의는 미변경, 텍스트 색만 교체 |
| 키보드 포커스 | `:focus-visible { outline: 3px var(--primary-a11y) }` 전역 추가 (base.css) |
| 본문 바로가기 | `.skip-link`(포커스 시 노출) + `<a class="skip-link" href="#top">본문 바로가기</a>` 본문 최상단 |

- 검증: grayLv3 텍스트 잔존 0 · a11y 토큰 19곳 · skip/focus 마크업 확인 · dev 서버 200.
- **디자인 영향 최소**: #8d9299→#6c7074 미세 darken(둘 다 회색), 프로젝트 자체 a11y 토큰 사용.

## 4. ⚠️ 의사결정 필요 — primary 버튼 대비

- 흰 글씨 / `--primary`(#2e6ff2) = **4.49:1** (4.5에 0.01 미달). `--primary-a11y`(#2861d2)면 5.63:1 ✅.
- 단, primary 버튼 배경을 a11y로 바꾸면 **모든 주요 버튼·브랜드 블루가 살짝 진해짐**(시각적 브랜드 변화).
- **선택**: (A) 현행 유지(4.49, 사실상 통과 수준) / (B) 버튼 배경을 `--primary-a11y`로 darken(엄밀 통과). → 브랜드 톤 변화 감수 여부는 운영 판단.

## 5. 후속 (별도 단위)

- 배포 후 스크린리더(보이스오버)·키보드 탭 순서 실사용 점검.
- 강사 이미지 alt 는 존재(적절). 랜드마크(header/main/footer) 존재.
- 신청 폼 생성 시(구글폼 외 자체폼이라면) label-input 연결 재점검.

## 6. 우선순위 맥락
